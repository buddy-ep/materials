📖 Zero Conditional

① FACTS – it always happens

Use it for things that are always true: science facts and habits. (สิ่งที่เป็นจริงเสมอ / เกิดขึ้นทุกครั้ง)

If + subject + V1(s/es) , subject + V1(s/es)
SentenceExample
✅ ประโยคบอกเล่าIf you heat water to 100 degrees, it boils.
✅ ประโยคบอกเล่าIf you put soft chocolate in the freezer, it gets hard.
❌ ประโยคปฏิเสธIf there is no rain, the grass doesn't grow.
❌ ประโยคปฏิเสธIf plants have no light, they can't grow.
❓ ประโยคคำถามWhat happens if you eat too much chocolate? – You feel sick.

💡 Both parts use the Present Simple. Don't use will here!

② ADVICE & INSTRUCTIONS

The second part can tell someone what to do. (ให้คำแนะนำ / บอกให้ทำ)

If + subject + V1 , V1… / don't + V1… / you can… / you need to…
Example (WB p.49)Second part
If you want an apple, take one from the kitchen. คำสั่ง
If you don't like the ice cream, don't eat it. คำสั่งปฏิเสธ
If you need help, please phone me. คำสั่ง
If you don't have a first course, you can have a pudding. can + V1
If you want to learn the guitar, you need to practise every day. need to + V1

✏️ The comma rule (กฎเครื่องหมาย ,)

Where is if?Comma?Example
At the start✅ YesIf it rains, I take my umbrella.
In the middle❌ NoI take my umbrella if it rains.

⚠️ Watch out! Common mistakes

❌ Wrong✅ RightWhy?
If you heat ice, it will melt.If you heat ice, it melts.Facts → Present Simple, not will
If it rain, I take my umbrella.If it rains, …it / he / she → add -s
If you eats too much, …If you eat too much, …you → no -s
If you need help please phone me.If you need help, please phone me.Don't forget the comma
If you need help, phones me.If you need help, phone me.Instructions → V1 (no -s)

💡 Exam tips

✅ Always true / a fact → If + Present Simple, Present Simple
✅ it / he / she → verb + s/es (it boils, it melts)
✅ If at the start → put a comma ( , )
✅ Advice → If…, + V1 (phone me, take one, don't eat it)
